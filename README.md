# Zakázky — Eva Goldšmíd × František Dron

Sdílená nástěnka zakázek. Obě strany vidí to samé a obě můžou psát:
studio i tým Eva Goldšmíd. Běží na GitHub Pages, data leží
v soukromém repu `frantisekdron/eva-zakazky-data`.

**Živě:** https://frantisekdron.github.io/eva-zakazky/

Kokpit vzniká ze společné šablony (skill `kokpit-zakazek` na Frantově Macu).
Společné soubory (`index.html`, `styles.css`, `app.js`, `vendor/`) se tady
ručně neupravují — přepíše je příští aktualizace šablony. Vlastní tohohle
kokpitu jsou `config.js` (přístup a jména), `znacka.css` (barvy), `icon.svg`,
`manifest.json` a tohle README.

Přístup (klíč a dvě hesla) nastaví `python3 nastav_pristup.py`.

## Návod pro tým Eva Goldšmíd

*(tuhle část můžeš přeposlat)*

Otevři **https://frantisekdron.github.io/eva-zakazky/**, zadej heslo a přidej si stránku na plochu telefonu.
Heslo si prohlížeč pamatuje.

Nahoře jsou **Poznámky a úkoly** — co je potřeba vyřešit. Pod nimi
**zakázky**: u každé adresa, odkaz na inzerát, fotky, vizualizace,
3D prohlídka, půdorysy, nápady na scénář, videa a bannery. Klikem se
otevře detail, videa se přehrají přímo tam.

Ke každé položce jde napsat komentář (bublina vedle ní). Zakázku, video
i odkaz můžeš sám přidat, přepsat nebo smazat. Nic se nemůže nenávratně
ztratit — každá změna je v historii.
